# 0007 — A matching install stamp is not a matching node_modules

**Date:** 2026-09-08 (poisoning 2026-09-07; diagnosed 2026-09-08)
**Anchors:** task #2654 (scrollbar freeze) / #2656 (pipeline root cause), fix PR #1992,
deployed chunk `1e7rkr3zcdkcu.js` (md5 `3f343f496e3188e846e8bb144e4b501e`),
`cli/commands/_repo.py:_ensure_frontend_deps`, `ui/web/scripts/check-bundle-integrity.mjs`.
Poisoning actor not identified (no matching session in Loki; both `~/Ava` and the
prod source carry pnpm markers from ~2026-09-07 21:00–21:05).

## Summary

The production bundle shipped `@radix-ui/react-scroll-area`'s
`addUnlinkedScrollListener` as an empty shell — its rAF polling loop had been
compiled away — freezing every scrollbar thumb between scroll events. The repo
source, the lockfile, and CI were all innocent: a pnpm install in the prod
source re-resolved the `^1.2.10` range to radix 1.2.18, whose dist (esbuild
keep-names emit, ≥1.2.16) marks the polling IIFE `@__PURE__`; the production
minifier (SWC compress, Next 16) trusts the annotation and drops the loop as an
unused pure call. The converge check that should have caught the drift only
hashed the lockfile, and a foreign package manager touches neither lockfile nor
stamp. Guardrails: converge now verifies node_modules against the lockfile, and
CI fails any bundle carrying the degradation signature.

## Root cause

Three independent facts had to combine:

1. **Version drift outside the lockfile.** `_ensure_frontend_deps` proves only
   that the lockfile is unchanged since the last `npm ci` — the stamp is a hash
   of `package-lock.json`. pnpm reads no such lockfile: it re-resolves ranges
   (`^1.2.10` → 1.2.18) and leaves both lockfile and stamp byte-identical.
   The poisoned tree passes every converge check forever.
2. **An upstream annotation the minifier trusts.** radix ≥1.2.16 ships dist
   emitted with esbuild keep-names: every function is wrapped in `__name(...)`
   and the polling IIFE carries `/* @__PURE__ */` (intended to mark the
   identity wrapper pure). SWC compress treats the annotation as license to
   drop the *entire call* as an unused pure expression. Executing it has side
   effects — rAF scheduling and handler calls — which are silently discarded.
   The corpse is then constant-folded: `rAF` is never assigned, so
   `cancelAnimationFrame(rAF)` becomes `cancelAnimationFrame(0)`.
3. **The deployment path is not the CI path.** CI builds `npm ci` trees from
   the lockfile (radix 1.2.10 — annotation-free) and stayed green while prod
   served the broken bundle. Nothing in the pipeline compared the served
   artifact against a known-good build.

**Why every safety net missed it:**

- *The converge stamp* — designed for "lockfile changed", not "node_modules
  changed under an unchanged lockfile". A hash of the lockfile cannot see a
  foreign install by construction.
- *The frontend test suite* — runs in happy-dom against dev-mode (unminified)
  imports; the degradation exists only in the minified production artifact, so
  no unit or component test could have failed.
- *CI's production build* — ran the *correct* dependency version the whole
  time. CI green was true and irrelevant: prod and CI had diverged at the
  dependency layer.
- *#5880's clean-build verification* — the claim "a clean 1.2.18 build keeps
  the full polling loop" contradicted the deterministic minifier behavior
  (reproduced byte-for-byte); the check most likely matched other rAF loops in
  the same chunk (e.g. the ResizeObserver handler) rather than the function
  body. Recorded here so later readers verify function bodies, not chunk
  presence.

## Guardrails added

- **Converge verifies node_modules against the lockfile**
  (`cli/commands/_repo.py:_node_modules_drift`, called from
  `_ensure_frontend_deps` when the stamp matches): foreign package-manager
  markers (`.modules.yaml`, `.pnpm`) and installed versions of direct
  dependencies vs the lockfile. Any drift falls through to `npm ci`, which
  wipes and restores the locked tree. This is the prod-side guard — it runs on
  every `ava start` / `ava cluster update` before the build.
- **CI fails degraded bundles** (`ui/web/scripts/check-bundle-integrity.mjs`,
  wired into the frontend CI job after the production build): denies the
  `cancelAnimationFrame(0)` corpse signature in any chunk. rAF ids start at 1,
  so that literal exists only as the folded corpse of the eliminated loop —
  the check needs no symbol names and fires on the degraded build alone (the
  real degraded chunk trips it; a healthy production build has zero hits). A
  future lockfile bump to radix ≥1.2.16 turns CI red at the PR, before any
  deployment can carry it. A positive "the polling function must be present"
  assertion was considered and rejected: the function's name is mangled away
  in healthy production emit (the name string in the degraded chunk comes from
  radix's own `__name` keep-names wrapper, a ≥1.2.16 dist artifact), so any
  name-based rule fails every healthy build.
- **Component-level regression test** (PR #1992): the scrollbar no longer
  depends on radix's private polling, so a recurrence degrades gracefully
  rather than freezing the UX — defense in depth, not the pipeline fix.

**Still unguarded, deliberately.** The check is coupled to this function and
this corpse signature; any other library shipping `@__PURE__`-annotated
side-effectful calls can still be emptied silently. The general fix belongs
upstream (the annotation semantics in the minifier), which is why the tripwire
fails loudly instead of pretending the class is closed.

## Lessons

- **A stamp proves what you hashed, nothing else.** The lockfile hash answers
  "has the lockfile changed since the last install"; "does node_modules match
  the lockfile" is a different question that needs its own check.
- **The served artifact is the source of truth, not the source tree.** When
  prod behavior and clean builds disagree, diff the dependency state the build
  actually consumed — version drift is cheaper to check than cache theories
  and it was the answer here.
- **Deterministic minifiers do not have moods.** A byte-identical input under
  the same toolchain produces byte-identical output; a claim of different
  output is evidence of different input. Find the input.
- **CI green does not certify prod.** A pipeline that builds from the lockfile
  cannot vouch for an installation a foreign tool mutated; guard the
  installation boundary itself.
