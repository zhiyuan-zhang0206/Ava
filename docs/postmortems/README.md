# Historical incident analyses

These records explain how a failure escaped and the evidence and guardrails
identified at the time. Preserve the incident account rather than rewriting it as
current operations. Follow [the contribution guide](../contributing.md) for work,
[current defensive patterns](../conventions/defensive-patterns.md) for reusable
lessons, and component-local `docs/` for current behavior.

Use [_template.md](_template.md) for a new systemic incident analysis. Routine bugs
caught by existing checks can remain in Git history.
