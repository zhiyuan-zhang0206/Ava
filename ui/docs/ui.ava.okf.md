# User interfaces

The UI domain contains two client implementations:

- [[ui/web/docs/web.ava.okf.md]] — the web frontend and its component, state and data-flow documentation.
- [[ui/app/docs/app.ava.okf.md]] — the desktop application.

The clients use the gateway APIs described by
[[gateway/docs/gateway.ava.okf.md]]. Their component nodes own implementation
details; this overview groups the clients without duplicating them.
