## Design Context

### Users

The cluster operator uses the quota panel to decide which account can work
now and when limited capacity will recover.

### Brand Personality

Calm, concise, factual. The operator explicitly prioritizes reset/recovery
times and rejects complementary used/remaining figures shown together.

### Aesthetic Direction

Use the console's existing light/dark tokens and typography. Prefer readable
full-width rows to compressed tiles; important information stays visible on
narrow screens without hovering. This direction scopes the quota panel.

### Design Principles

1. Make each quota window's reset time the primary information.
2. Show remaining quota once, without its complementary used percentage.
3. Distinguish known zero, unavailable data, stale data, and an actual error.
4. Show supported manual-reset availability separately from scheduled resets.
5. Keep generic plugin rendering independent of provider-specific parsing.
